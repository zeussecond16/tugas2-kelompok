# Penjelasan Adaptivitas Grid Layout

Pengaturan jumlah kolom pada `LazyVerticalGrid` dalam aplikasi ini ditentukan secara dinamis menggunakan parameter `GridCells.Adaptive(minSize = 220.dp)`. Mekanisme ini mengharuskan Compose menghitung jumlah kolom berdasarkan ruang horizontal yang benar-benar tersedia setelah dikurangi padding horizontal. Pada layar ponsel (`COMPACT`, lebar `< 600.dp`), ruang horizontal terbatas menyebabkan grid hanya memuat 1 kolom kartu agar batas minimum 220 dp terpenuhi secara optimal. Ketika aplikasi dibuka pada layar tablet atau laptop (`EXPANDED`, lebar `>= 840.dp`), total lebar layar meningkat dan `DashboardSideRail` selebar 88 dp muncul di sisi kiri. Sisa lebar area konten sebesar kurang lebih 912 dp kemudian dibagi oleh grid, sehingga secara otomatis menghasilkan 3 kolom kartu tanpa perlu mengubah logika kode secara manual. Dengan demikian, adaptivitas grid berpatokan langsung pada batas `minSize` 220 dp dan breakpoint ruang jendela yang tersedia, bukan pada tipe fisik perangkat.
